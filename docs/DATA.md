# 데이터 정의 (C 담당)

계산 엔진(`calc_engine/`)이 쓰는 데이터와, 각 정의의 근거를 정리한다. 2026-11-19 기준.

## 1. 출처
- 서울 열린데이터광장 **OA-22175 「서울시 상권분석서비스(추정매출-행정동)」**
- 저작권자 서울특별시, 제공 서울신용보증재단(데이터분석팀, 02-2174-5075), 이용허락범위 **제한 없음**
- **2021~2025년**: '파일내려받기'의 연도별 zip (각 약 11MB, 압축 해제 시 약 30MB, **CP949**, 53개 컬럼, 연도별 구성 동일)
- **2026년 1·2분기**: 공식 zip이 아직 없어 **Sheet 화면의 CSV 내려받기**(화면 기본 조건 그대로, 2025Q1~2026Q2, 45MB, CP949)를 씀. 2026-11-19 받음
  - 같은 데이터인지 확인: Sheet의 2025년 67,113행이 공식 2025년 파일과 **숫자 전 칸 일치**. 다른 곳은 동 이름 7개뿐이고 원인은 Sheet 내려받기에서 '·'가 '?'로 깨진 것(예: 상계6·7동). 우리 8개 동은 해당 없음. 동 이름은 매핑표 기준으로 씀
  - 2026Q1과 2026Q2는 행 수가 같지만(16,659) 금액이 같은 행은 209개뿐이라 복사본이 아님
- **추정 매출**(카드 데이터 기반 추정치)이며 실제 매출이 아니다. 산출식: 추정매출액 = 카드결제금액 ÷ 보정비율 (상권분석서비스 이용안내)

## 2. 파일
| 파일 | 내용 |
|---|---|
| `calc_engine/data/region_map.csv` | 지역 5곳 ↔ 행정동 8개 (코드로 연결) |
| `calc_engine/data/sales_5regions.csv` | 원본에서 8개 동만 남긴 데이터. **8,385행**(2025Q4까지 7,652 + 2026년 733), 54열(지역 열 추가), **2021Q1~2026Q2**, UTF-8 |
| `calc_engine/data/answer_key.md` | 정답표 Q1~Q11. pandas와 파이썬 기본 csv로 따로 계산해 일치한 값만 기록. Q1~Q10은 2025Q4 기준, Q11은 2026Q2(사이트 대조) |
| `calc_engine/scripts/build_dataset.py` | 원본 CSV 여러 개 → `sales_5regions.csv`. 파일끼리 겹치는 행은 숫자가 모두 같은지 확인하고 앞 파일(공식 파일)을 씀 |
| `calc_engine/scripts/answer_key.py` | 정답표 다시 계산 |

원본은 `calc_engine/raw/`에 두고 git에서 제외한다. 다시 만들기 (공식 파일을 먼저, Sheet 파일을 마지막에):
`python calc_engine/scripts/build_dataset.py calc_engine/raw/sales_dong_202?.csv calc_engine/raw/sales_dong_sheet_2025Q1_2026Q2.csv`

| 홍대 | 서교동 (11440660) |

| 강남 | 역삼1동 (11680640) |

- 8개 코드 모두 2021~2025년 동안 바뀌지 않음을 확인

## 4. 엔진 컬럼 (API 이름 → 원본)
| 종류 | API 이름 | 원본 컬럼 |
|---|---|---|
| 차원 | `region` / `dong` / `industry` / `quarter` | 지역 / 행정동_코드_명 / 서비스_업종_코드_명(62종) / 기준_년분기_코드 |
| 측정 | `est_sales`, `est_count` | 당월_매출_금액, 당월_매출_건수 |
| 측정 | `weekday_sales`, `weekend_sales` | 주중·주말_매출_금액 |
| 측정 | `mon_sales` ~ `sun_sales` | 월~일요일_매출_금액 |
| 측정 | `time_00_06_sales` ~ `time_21_24_sales` | 시간대_00~06 ~ 21~24_매출_금액 |
| 측정 | `male_sales`, `female_sales` | 남성·여성_매출_금액 |
| 측정 | `age_10_sales` ~ `age_50_sales`, `age_60_plus_sales` | 연령대_10 ~ 60_이상_매출_금액 |
| 없음 | `store_count` | 이 데이터에 점포수 없음 → `COLUMN_NOT_FOUND` |

업종 묶음(C 제안, 팀 검토 필요): 카페=커피-음료 / 음식점=한식·중식·일식·양식·제과·패스트푸드·치킨·분식 / 주점=호프-간이주점 / 편의점=편의점 / 소매=CS3 코드 전체 / 의류=일반의류 / 미용=미용실·네일숍·피부관리실

## 5. 정의별 근거 수준
| 항목 | 판단 | 근거 수준 | 근거 |
|---|---|---|---|
| `당월_매출_금액`·`당월_매출_건수`의 기간 | **분기 3개월 합계** | **확인됨** (제공 기관 사이트 대조) | 상권분석서비스, 서교동 2025년 4분기: 지도 매출 3,688.9억 원 = 데이터 368,888,000,781원. ÷3 ÷점포수(8,820) = 13,941,345원 → 사이트 "점포당 월평균 매출 1,394만 원" 일치. 건수 14,663,460 ÷3 ÷8,820 = 554.2 → "월평균 매출건수 554건" 일치. **2026년 2분기도 같은 방식으로 일치**: 매출 364,283,677,777원 = 지도 3,642.8억 원, ÷3 ÷8,783 = 13,825,332원 → "1,383만 원", 건수 → 582.1건 → "582건". 사이트 요일별 매출 단위 "3개월간 점포당 평균" |
| 세부 컬럼(주중·주말, 요일, 시간대)의 기준 | 총계와 같은 기준 | **확인됨** (전 행 대조) | 금액·건수 모두 8,385행 전부(2021Q1~2026Q2)에서 합 = 총계 |
| 성별·연령 합계 < 총계 | 법인 매출(성별·연령 없음)이 주된 이유 | **간접 근거** | 상권 데이터셋(OA-15572) FAQ. 서울 전체 2021Q4 성별 부족분 중앙값 1.6%, 최대 100.0%(반올림). 행정동 데이터 적용 여부는 제공 기관 확인 전 |
| 2021~2023년을 2024년 이후와 같은 기준으로 비교 | 판단 보류 | **미확정** | 안내문(2026-07-03): 표준단위구역 기준 매출액은 2021년부터 있어 2021년 이후만 제공. 그러나 파일 수정일이 2021·2022년 2023-10-31, 2023년 2025-01-13으로 안내 이전. 재산출 여부 문의 예정. 엔진은 2023년 이전 분기를 쓰면 notes `pre_2024_basis_unconfirmed` |
| 카드사 범위 | 판단 보류 | **미확정** | 출처마다 다름: 이용안내 "신한카드", 사이트 리포트 "5개 카드사", 서울디자인재단 보도자료 "BC·KB·신한" |
| 외국인 결제가 성별·연령에서 빠지는지 | 판단 보류 | **미확정** | 출처 미확인 2차 설명만 있음 |
- **쓰지 않는 해석**: "당월 매출 = 분기 월평균이므로 ×3"(서울디자인재단 보도자료, 점포-상권 데이터 대상). 행정동 데이터에 적용하면 사이트 숫자와 3배 어긋남

## 6. 표시 규칙 (화면·설명 문장 공통)
API는 반올림하지 않은 값을 보낸다. 표시할 때만: 금액 = 억 원 소수 첫째 자리(5,192.5억 원) / 비율 = % 소수 첫째 자리(44.5%) / 증감률 = 부호 붙인 %(+4.8%) / 건수 = 쉼표 정수(224,959건)
